Marvel vs DC Battle Bot ⚔️
A complete, production-ready turn-based battle game for Telegram groups, built with Python, Flask, and python-telegram-bot. Deploy seamlessly on Render Web Services.

🤖 BotFather Setup
Open Telegram and search for @BotFather.
Send /newbot.
Follow the prompts to name your bot (e.g., "Marvel vs DC Battle").
Copy the BOT_TOKEN provided by BotFather.
💻 Local Installation
Clone the repository (or create the files locally).
Create a virtual environment:
python -m venv venvsource venv/bin/activate  # On Windows: venv\Scripts\activate
